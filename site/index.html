Action Economy // จังหวะปฏิบัติการ

ในเทิร์นของตัวเอง นักบินเลือกใช้คำสั่งและระบบของ Mobile Suit ตามโควตาด้านล่าง

ACTION

1 ครั้ง / เทิร์น

  • Attack โจมตีด้วยอาวุธที่อยู่ในระยะ
  • Boost (Dash) เร่งเครื่อง เพิ่มระยะเคลื่อนที่เป็น 2 เท่าในเทิร์นนี้
  • Disengage ถอนตัวอย่างระมัดระวัง ไม่เปิดช่องให้ถูกโจมตีฉวยโอกาส
  • Evasive Maneuver (Dodge) ตั้งท่าหลบ การโจมตีใส่คุณได้ Disadvantage
  • Support (Help) ช่วยเพื่อนเล็งเป้าหรือคุมพื้นที่ ให้ Advantage กับการทดสอบที่เกี่ยวข้อง
  • Sensor Stealth (Hide) พรางตัวหรือลดการตรวจจับจากเซนเซอร์
  • Overwatch (Ready) ตั้งท่ารอและระบุ Trigger เพื่อใช้ Reaction เมื่อเงื่อนไขเกิด
  • Scan / Analyze / Comms สแกนสนามรบ วิเคราะห์เป้าหมาย หรือสื่อสารกับหน่วย
  • Use Equipment ใช้อุปกรณ์หรือระบบที่ต้องใช้ Action
BONUS ACTION

สูงสุด 1 ครั้ง / เทิร์น

ใช้ได้เฉพาะเมื่อสกิล ระบบ หรือความสามารถของนักบิน/หุ่นระบุชัดว่าใช้ Bonus Action ได้ เช่น ระบบเสริมที่ติดตั้งไว้

ไม่มี Bonus Action ให้ใช้ฟรีโดยอัตโนมัติ

REACTION

1 ครั้ง / รอบ

ใช้ได้ทันทีเมื่อ Trigger เกิดขึ้น จะเกิดในเทิร์นของคุณหรือนอกเทิร์นก็ได้

  • โจมตีฉวยโอกาส
  • เปิดระบบป้องกันหรือมาตรการตอบโต้ที่ระบุว่าใช้ Reaction
  • ทำตามคำสั่ง Overwatch ที่ตั้งไว้

▸ Movement // การเคลื่อนที่

เคลื่อนที่ได้ตามค่า ENGINE ของ Mobile Suit และแบ่งระยะเดินก่อนหรือหลัง Action ก็ได้ เช่น เคลื่อนที่เข้าที่กำบัง → โจมตี → เคลื่อนที่ต่อ หากใช้ Boost ให้เพิ่มระยะเคลื่อนที่เป็น 2 เท่าตามกติกา

▸ Free System Interaction // ปฏิสัมพันธ์ฟรี

หนึ่งครั้งระหว่าง Movement หรือ Action สามารถหยิบ/เก็บอุปกรณ์ กดแผงควบคุม เปิดประตู หรือเปลี่ยนอาวุธที่เตรียมพร้อมได้ โดยไม่เสีย Action หากการกระทำนั้นไม่ระบุว่าต้องใช้ Action

▸ การโจมตีและความเสียหาย

ทอย d20 + ACC เทียบกับ AC ของเป้าหมาย เมื่อโจมตีโดนให้ทอยความเสียหายตามอาวุธ เมื่อ HP เหลือ 0 Mobile Suit หยุดปฏิบัติการ Smoke Charge สร้างควันรัศมี 2 ช่องและให้ +2 AC ตามเงื่อนไขการยิง ส่วน Wire-Guided Remote Weapon ต้องมี NEW มากกว่า 3

REACTION // TRIGGER

โจมตี
ฉวยโอกาส

ใช้ Reaction โจมตีระยะประชิดใส่ศัตรูที่เผลอเปิดช่องขณะเคลื่อนที่

Triggerศัตรูที่คุณมองเห็นเคลื่อนออกจากระยะโจมตีประชิดของคุณ ระยะพื้นฐานคือ 1 ช่อง หากอาวุธกำหนด Reach ไว้ต่างออกไปให้ใช้ค่าของอาวุธ
จังหวะโจมตีโจมตีก่อนเป้าหมายพ้นระยะ Reach จึงยังถือว่าอยู่ในระยะโจมตี

ไม่เกิด Attack of Opportunity เมื่อ

  • เป้าหมายใช้ Disengage ก่อนเคลื่อนออก
  • เป้าหมายเคลื่อนที่วนอยู่รอบตัวแต่ยังไม่พ้น Reach
  • ถูกผลัก ดึง หรือกระเด็นโดยไม่ได้ใช้ Movement ของตัวเอง
  • เคลื่อนย้ายฉับพลันหรือ Teleport ออกจากระยะ
  • คุณมองไม่เห็นเป้าหมาย เช่น ถูกพราง ล่องหน หรือตาบอด
